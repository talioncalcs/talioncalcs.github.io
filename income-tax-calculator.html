Income Tax Calculator – Take Home Salary

Estimate annual income tax payable and approximate take-home income. This tool lets you enter gross annual income, common deductions, and choose a tax regime. It includes editable example tax slabs so you can match the current fiscal year's rules.

Edit the JSON if your fiscal year has different slab thresholds or rates. Use null for "above" (no upper bound).

How the calculator works

1) Taxable income is calculated as: Taxable = Gross income − (Standard deduction + allowed deductions you enter).
2) The calculator applies the selected slab table to the taxable income to compute tax for each slab segment, sums slab taxes, then adds statutory cess (default 4%). If you enable rebate, the calculator reduces tax if taxable income falls under the rebate threshold — but make sure slab values and rebate rules match the fiscal year you are modelling.

Important: This tool provides an estimate only. Tax laws, slab thresholds, rebates and cess rates change — always confirm with the current official notifications or a tax professional before making decisions.

When to use this calculator

Use it to get a quick estimate of annual tax and approximate monthly take-home after tax. Helpful while negotiating salary, planning investments to use deductions, or comparing old vs new tax regime outcomes.

How to ensure accuracy

Before relying on the numbers, update the slab JSON to match the official slabs for the fiscal year you're modelling, set correct deduction values, and confirm rebate/relief rules. This calculator intentionally leaves slab editing open so you can keep it current without code changes.

Frequently asked questions

Should I trust the default slabs? Default slabs are illustrative. Update them to the current fiscal year's official slabs for precise results.

Does this include other components like HRA or exemptions? This is a simplified estimator. HRA and some exemptions are complex (require rent, city, receipts). You can model them by adding their net effect as an "Other Deductions" value.
